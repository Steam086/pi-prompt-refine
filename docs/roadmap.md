# 路线图

维护者在这里跟踪首发与近期验证。长期取舍和待论证方向见[设计原则](design.md)。

## 原生 TUI 首发

- [ ] 在 `0.1.0` 最终候选 commit 上取得外部 CI 结果。此前版本已在 macOS 做过人工验收，核对候选版与当时的差异，补测受影响的操作和尚未覆盖的场景。见[人工验收清单](macos-smoke-test.md)。
- [ ] 复核最终锁文件、目标 Pi 宿主版本和候选 tarball。确认 Git 历史可公开，核对 npm 名称、账户、2FA、版本及制品摘要，由维护者另行批准发布与打 tag。发布后按固定版本验证 registry 安装、卸载及公开文档链接。见[发布清单](release.md)。

## 改写质量与体验

- [ ] 用真实模型对照检查表达是否更清楚、指代是否准确，以及硬约束、字面材料和授权范围是否保留。追踪连续修订中的语义漂移。见[语义验收样例](optimizer-evaluation.md)。
- [ ] 用真实样例评估单次请求的上下文选择与 token 估算，比较保真度、延迟和用量。见[上下文选择与预算](design.md#上下文选择与预算)。

## 暂缓发布的 Web 集成

Web 子包仅供本地开发与隔离验证。重新评估发布前，先改善实际使用体验，并验收浏览器中文 IME、可访问性和部署认证。见 [Web 子包说明](../packages/pi-web/README.md)及[隔离验收记录](multi-surface-acceptance.md)。
