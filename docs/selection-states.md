# Tasks 选中状态：视觉方案与验证

## 方案

- 顶部 `Preview / Usage / Settings`：激活项由 `toolPendingBg` 改用任务树已有的 `selectedBg`；保留中性 `text` 加粗，并仅为标签文字加下划线。非激活项仍为普通字重的 `muted`。下划线提供不依赖背景色差的识别线索，不增加行数、字符或边框。
- 任务树：保留整行 `selectedBg`、原有树形连接符与缩进；已有的 `›` 使用 `accent` 加粗，选中名称在紧凑行中也加粗。宽屏的原稿正文、运行元数据及行间留白保持原样。
- 统一采用“主题选中背景 + 中性粗体名称 + 轻量辅助标识”。未新增或硬编码产品颜色，浅／深主题直接使用宿主调色板。绿色 `✓ Done`、其他状态色与树形连接符的 `muted` 语义不变。
- 选中仍表示阅读／操作目标，而非键盘焦点：切到右侧阅读时不撤掉选中样式。顶部 Tab 表示当前页面，即使子视图暂时接管输入也不改变其身份。
- 不改任务／页面选择、快捷键、状态管理、布局尺寸或顶部快捷键区域；Settings 内部 `Context / Optimizer / Advanced` 分组样式保持原样。
