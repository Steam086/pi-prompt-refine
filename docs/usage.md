# 使用说明

安装与最小流程见 [README](../README.md)，配置字段见 [配置参考](configuration.md)。本扩展是无工具的后台改写器，不执行 prompt 中的任务。

## 快捷键：打开与捕获，不覆盖

默认入口是 `Ctrl+\`（Control + 反斜杠，不是 Command）。

| 当前情况 | 行为 |
| --- | --- |
| 已选模型，Pi 输入框是新的非空文本（包括首次输入） | 追加 `○ Unsent` 条目并直接选中新原稿，打开工作台；**不自动请求**。可先按 `i` 编辑或按 `p` 添加 Preferences，再按 Enter 启动 |
| 输入没有变化或已经捕获 | 定位对应任务，保留该任务内已有的选择；不重复入列或调用模型 |
| 输入框为空 | 只打开工作台，恢复上次选择；没有条目也可按 `p` 管理 Preferences |
| 没有配置模型 | 打开面板，先用 `m` 或 `/refine model` 选择 |

生成中也使用相同规则。新输入不会取消或替换已有请求，不会清空 Pi 输入框。比较保留空白与换行，不做语义去重。未变化的旧输入不会因为旧 round 归档而重复捕获；清空工作区也不会让下一次快捷键自动请求。

快捷键带着输入打开时，以该输入对应的任务为目标，优先当前轮次；新捕获的原稿从顶部开始阅读，不沿用旧任务的选择和滚动位置。已接受文本定位其对应结果。Unsent 原稿按 Enter 成功启动后，自动选中该原稿下的模型运行（包括排队中的运行）；启动被拒绝则保留原稿选择。关闭工作台不会停止任务，后台完成也不会自动弹窗或移动列表选择。超长输入或不可用模型会提示，已有内容保留。

## Round：发送后自动归档

一个 round 包含一份冻结上下文、多份 prompt，以及各 prompt 的模型运行和结果。

1. 第一份输入捕获时冻结可见历史、系统模板、项目资源及上下文配置。
2. 同 round 的新 prompt 共享这份背景；追加模型运行、查看详情、接受到编辑器、修改配置均不切 round。
3. **Pi 发出用户消息 `message_start` 后**，当前 round 自动归档。适用于 Pi 输入框直接提交和扩展明确发送；原始 `input`、`before_agent_start` 可能仍被拦截或失败，不作为成功发送依据。
4. 下一份新输入捕获时，才获取最新可用上下文并创建新 round。没有手动刷新操作，也不承诺包含尚未生成的 Pi 回复。

归档不是取消：旧请求继续运行，结果归属旧 round；旧的未发送条目仍绑定原快照。列表默认显示所有保留轮次，当前轮次在上，旧轮次在下并变灰，原稿带 `Earlier ·`。右侧不再重复显示顶部警告，仅在详情 `Record` 中弱化标注 `Earlier context`，正文保持正常阅读颜色。编辑旧原稿会创建当前 round 的副本；内存中仍有完整快照的旧条目可直接使用旧背景，磁盘恢复记录则必须复制到当前 round 后再运行。

默认目录树在 round 首次需要时收集并共享；显式 `@directory` 按 prompt（含修订要求）收集并冻结。相同输入的并行模型运行共享收集结果，一条请求取消不取消另一条的上下文准备。规则和技能来自捕获时的 Pi 资源，不读取源码或技能正文。

## 工作台与统一 Usage

顶层页面为 **Preview / Usage / Settings**，不再有独立 History 页。`/refine history` 保留为 Usage 的兼容别名。

宽屏采用左侧「原稿 → 各次模型运行」两层树、右侧正文；窄屏通过 Tab 切换列表与阅读。Preview 中可编辑 Unsent 另有内联偏好区，Tab / Shift+Tab 循环列表、原稿阅读、偏好选择。父节点可选中，Unsent 是没有运行子节点的原稿。子节点代表一次运行，同一模型重试也保留独立记录。当前轮次优先，各轮次内按最新任务组排序，组内最新运行在上；新增运行使该组前移，完成不会重新排序或移动选择。

| 列表操作 | 行为 |
| --- | --- |
| ↑↓ / Page Up / Page Down | 选择父节点或运行子节点 |
| Tab / Shift+Tab | 切换选择／阅读焦点；Preview 的可编辑 Unsent 还可切到偏好选择，从原稿列表 Shift+Tab 可直达；阅读时方向键滚动正文 |
| Enter：Unsent 原稿焦点 | 携带该原稿已选 Preferences，使用默认优化模型启动；偏好焦点内只阅读全文；空白不能启动，旧条目仍使用旧背景；不发送给 Pi |
| `p` | 打开 Preferences；可编辑 Unsent 原稿可选择并带回，空工作区及其他原稿／运行仅浏览和管理库；进入 Inspect 前后相同 |
| Enter：其他条目 | 查看原稿或运行详情，包括排队、运行、失败和取消；不 Apply、不写 Pi、不发送 |
| `n` | 顶部新增空白原稿并进入编辑；无需先配置模型 |
| `i` | 编辑选中条目所属原稿；当前 Unsent 原地修改，已运行或旧轮次创建当前轮次副本 |
| `f` | 选中有结果且背景可用的运行，直接进入该结果详情及 Revise；不发送请求 |
| `m` | 选择模型，Enter 直接为该原稿启动一次运行；不更改默认模型 |
| `x` | 只停止选中的排队／运行子节点；父节点不批量停止，完成记录保留 |
| `a` | 将选中运行的结果写入 Pi 输入框，不发送；父节点不自动挑选模型结果 |
| `?` | 打开只读的完整动作／反馈页，窄屏被省略的操作可在此查看；Esc 返回后再执行 |
| `b`（Usage） | 查看历史保存状态、sidecar 路径和已保存／仅内存／容量省略的运行编号 |
| Ctrl+E（阅读页） | 展开／收起工作区高度，不改变选择目标或发送内容；冲突时按底栏显示的备用键操作 |
| ← / → | 循环切换 Preview / Usage / Settings；内联偏好焦点内暂停，先 Esc 返回 |
| Esc / `q` | 返回／关闭；关闭不取消后台任务 |

原稿编辑器中 Enter 只保存，Shift+Enter / Ctrl+J 换行，Esc 取消本次编辑；取消新建或复制会移除临时草稿。保存后返回列表，再按 Enter 才请求模型。编辑期间原稿启动或会话换轮会拒绝旧保存，避免修改已经提交的输入。显式新建允许相同文本，快捷键自动捕获仍保持去重。

左侧模型子项状态右对齐，模型名占剩余空间并按需截断，不预留固定宽度的状态列。右侧顶部显示模型／状态、Provider 与 Thinking，以及 `7s · ↑1.2k ↓300 · ≈$0.012`：↑ 为含缓存的总输入，↓ 为输出。缓存读取、写入、命中率等完整统计在 Usage 中查看。运行中耗时使用强调色，每秒更新；排队不计入运行耗时。顶部固定，正文单独滚动。错误和上下文告警优先于辅助元数据；短窗口放不下的诊断进入滚动正文，不再丢弃。操作反馈在短窗口优先占用标题，滚动不清除反馈，`?` 可查看完整内容。窄屏优先保留接受／发送提示，↑↓ 提示随选择／阅读焦点变化。旧上下文归属移入 Record。

任务列表已有“树 + 摘要”分栏，摘要内部不再分栏；仅在 Enter 进入 Preview 结果详情后，内容区至少 90 列（终端至少 94 列）时采用约 65/35 双栏：左侧当前结果，右侧原稿、本次修订要求及修订前结果。顶部模型与状态相邻，Provider、Thinking、耗时、Token 和费用合并为紧凑摘要，按需换行。`o` 在两栏间切换滚动焦点，↑↓ / Page Up / Page Down 只滚动当前栏；窄屏默认只显示结果，`o` 切换参考信息，两侧分别保留阅读位置。切换参考信息不改变接受、编辑或修订的目标。结果 Preview 不常驻用量明细、设置或模板库管理；只有可编辑 Unsent 提供轻量内联选择。Compare 仍使用原有并排比较。

详情内保留 `e` 编辑结果、`f` 修订、`s` 发送；`n` 仅在列表新建，列表不再把 `e` 作为原稿编辑别名。列表／详情不支持隐藏 `g` 重试，统一用 `m` 运行原稿；`p` 在空工作区、原稿和运行详情均可打开 Preferences；只有有完整背景且未启动的 Unsent 原稿可选择并带回，其余只管理库；结果新增修订要求仍通过 `f` → Preferences。无效操作显示提示，不回落到其他已 Apply 结果。Usage 是实时视图，完整用量和记录信息在正文后，方向键滚动查看。手工编辑标注 `Manual edit · no model call`，不当作模型调用。

### 高度与长文阅读

工作区打开时按任务树与初始正文需求选择紧凑高度，正常窗口通常为 **18–24 行**（包含标题、页签和底栏），同时受终端约 65% 的默认预算及至少预留 4 行的约束；矮窗口允许低于 18 行。短原稿后只留一行间隔接 Preferences，原稿不再为了填满区域补空行，回收的空间用于展示更多选项。长原稿与偏好列表仍各自有界滚动；极短窗口优先显示当前焦点的可操作内容。

同次打开期间，切换任务、焦点、顶层页及子页、搜索／勾选、后台完成、偏好库加载或删除记录均不自动改变总高度。只有重新打开、终端尺寸变化或手动展开／收起才会重新分配外部空间；异步加载完成后不会突然长高。

阅读页按 **Ctrl+E** 可将高度展开至终端约 85%，仍至少预留 4 行；阅读宽度不变。收起恢复本次打开选定的紧凑高度（resize 后按新尺寸预算），结果／原稿／参考资料分别保留阅读锚点，接受／发送目标不变。文本超出视口后内部滚动，标题、页签和底栏保留在视口外。没有可用高度差时不显示展开提示。

搜索、原稿编辑器、Preferences 子页、帮助和确认框不截获该阅读快捷键。Revise 的 Ctrl+E 仍仅切换“来源＋输入／完整输入”，不会增高外框。阅读快捷键避让 Pi 已解析的非编辑绑定与 Preferences 键，依次回退到 `=`、`+`；都冲突时停用，以实际底栏／动作页提示为准，不保证识别其他扩展或终端自身截获。

### 并行优化与对比

选中原稿或模型子节点，按 **m → Enter** 使用另一个模型运行。选择器支持搜索，最近使用和收藏的其他模型优先，显示当前任务下各模型的 Running / Queued / Done / Failed 状态。Thinking 初始沿用选中运行的配置并按目标模型能力调整，选择器中可修改，只作用于本次请求。

- 所有比较运行使用共同的 original prompt、系统模板和会话背景；从修订或手工编辑结果上按 m 也不会把输出当成新输入。
- 默认模型／thinking 通过 Settings 或 `/refine model` 修改；一次对比不持久化这些设置。
- 相同模型与 thinking 已在该原稿下运行时，定位已有请求；完成后可以再次运行，保留之前的输出。
- 最多同时运行 **4** 个请求，超出后按提交顺序排队；顶部置新仅影响展示。超时从实际启动时计算。
- 每次运行独立取消、超时、失败；失败不自动重试、不自动切换 Provider。
- 正等待 Pi 发送确认时，暂停结果操作和模型选择，避免投递目标改变。

任务树和偏好列表的 ↑↓ 导航会在空间允许时保留前后相邻选项，接近视窗边缘便提前滚动，不等选中项贴到底边才显示后续内容；视窗内部移动保持列表稳定。偏好分组标题计入可见高度，不参与选择，极短窗口优先显示当前可操作项。浏览不会自动勾选或提交。

主界面上下选择同级模型即可快速阅读比较。Enter 结果详情后按 `c` 与同原稿的另一份结果对比，再按 c 切换比较对象，遍历后退出比较。宽屏并排显示，左侧是当前选中结果；Tab 交换当前选择，`a` 接受标题明确标出的模型／运行。窄屏显示当前结果，Tab 在两份结果间切换。比较只阅读，不会发起调用。

## 兼容结果页：接受与发送各自独立

`/refine view` 直接查看当前已应用结果；快捷键和无参数 `/refine` 打开工作台。结果页可以继续阅读原稿和 Markdown／源码视图。

| 按键 | 操作 |
| --- | --- |
| `a` | 接受到 Pi 输入框，**不发送** |
| `e` | 手工微调并保存新版本，不调用模型；保留原结果 |
| `f` | 输入修订要求，携带最初原稿、当前结果、本次要求调用模型 |
| `s` | 明确发送给 Pi；忙时使用 `followUp`，保留输入框草稿 |
| `g` | 使用该任务冻结输入后台追加运行并返回任务列表；完成后在列表查看，不替换当前结果 |
| `r` | 明确读取 Pi 当前草稿并发起 refine，仍使用当前 round 的上下文 |
| `[` / `]` | 切换当前展示模型的候选 |
| `o` / `v` / `?` | 原稿对照／Markdown 与纯文本／帮助 |
| ↑↓ / Page Up / Page Down | 滚动正文 |
| `z` | 恢复上次接受前实际被替换的 Pi 草稿 |
| `x`（兼容 `d`） | 停止当前预览请求或取消预览，不删除日志或停止其他任务 |
| `q` / Esc | 从列表进入的结果页返回工作台；直接 view 的结果页关闭返回 Pi |
| `Ctrl+\` | 关闭工作区，不接受或发送 |

接受／恢复若会覆盖后来修改的 Pi 草稿，需要确认；确认返回后重新检查草稿、候选 token 和 session。Apply 没有 Pi 编辑器副作用，因而不要求覆盖确认。手工编辑保存为独立版本，不会被其他请求完成覆盖。

兼容结果页中的已接受快照只读。可以在任务树／Usage 中选中历史结果，显式接受或编辑；只有内存中仍有完整背景时才能修订。这些操作不把旧 round 恢复为当前 round。希望使用当前背景再优化旧原稿时按 `i` 复制编辑。

发送待确认不等于模型处理完成。排队消息只有开始成为 Pi 用户消息后才归档；发送失败不切 round。发送超时只表示扩展未等到确认，不证明 Pi 队列中没有该消息，请检查队列后再重试，避免重复发送。普通 Pi 提交只归档 round，不猜测它对应哪条候选的明确发送事件。

## Input、Revise 与 Settings

- **原稿编辑**：主界面 n / i 使用原稿编辑器，保存不调用模型；n 新建空白原稿，i 编辑所选任务原稿。
- **兼容 Input**：`/refine view` 的 i 仍保留独立输入稿，Enter 在空工作区启动优化，已有内容时只追加未发送条目；Shift+Enter / Ctrl+J 换行。提交不写 Pi 输入框。按 session 保存运行期草稿，提交、关窗、切模型和后台完成都不清空；主动清空也被记住。
- **Revise**：列表选中可修订结果按 f，先进入该结果详情再展开输入区；Inspect / 兼容结果页也可按 f。默认聚焦补充要求，标题标明模型与 Run 编号，上方保留来源结果与阅读位置；小终端自动使用完整输入页。**Enter 换行、Ctrl+S 明确请求、Ctrl+E 展开／收起、Esc 返回**。输入时浏览快捷键只是文字，不会触发接受／发送；仅当窗口尺寸支持两种布局时，显示并启用 Ctrl+E 展开／收起。修改要求与原稿编辑分离，按结果身份保留当前工作区内的临时草稿（最多 100 份，关闭工作区后清除）。成功追加结果，失败／超时保留来源候选；输入绑定候选 token，目标变化后拒绝旧操作。修订使用来源冻结上下文，不采纳中途修改的 Context；恢复记录没有背景，不提供 Revise。
- **Settings**：Context / Optimizer 两组，Tab 或左右键切组；外侧边界左右键切顶层页。↑↓选择，Enter / Space 更改项目，Ctrl+S 保存 Context。Context／Thinking 已在进程内生效但写盘失败时，以警告显示 `Not persisted`；Context 留在 Settings，保留选择供 Ctrl+S 重试，不宣称保存成功。切页保留暂存设置；在 Settings 取消或关闭工作区时放弃未保存 Context。
- **Context 设置**：规则 `First request only` / `Always` / `Off`、默认目录树和技能元数据。规则 First 模式对修订省略规则，策略在 round 捕获时冻结。配置修改用于**下一 round**，不偷偷改变当前任务。
- **Optimizer 设置**：模型与 thinking 选择用于下一次显式启动，不改变主 Agent。系统编辑策略变更同样要等下一 round 捕获。配置持久化失败会明确提示仅进程内有效。

Revise 成功后的结果详情标记为 `Revised prompt`；Tasks / Usage 显示 `Revised` 和来源运行编号。详情包含原始任务、完整修订要求和修订前候选，长正文可滚动阅读；Preview 详情按 `o` 聚焦／切换原稿与修订要求参考区，兼容结果页按 `o` 直接查看原稿。恢复的最小历史若未保留修订前正文，会明确提示缺失；失败后保留的旧结果仍展示它自身的修订信息。

Revise 标题与来源 Run／模型分别强调：只有操作标题加粗，来源信息弱化。常规状态简写为 `Not sent`，Preferences 与完整要求入口在空间允许时同行显示，焦点仍分别切换。上方来源区标为 `Read-only reference`，不再显示被输入焦点暂停的滚动／切页提示。错误和快捷键冲突使用警告色，短窗口优先保留异常反馈，而不是将其随第二行标题一起隐藏。

## 保存与复用编辑要求（Preferences）

### 浏览与管理

Pi 输入框或 Refine 工作区为空时，可直接打开工作台按 **p** 浏览库及 **Add / Edit / Delete**，无需新建原稿或请求模型。Preview / Usage 中选中原稿、排队／运行／已完成的子节点均可打开；Enter 进入 Inspect 前后权限相同。

除可编辑 Unsent 原稿或显式 Revise 外，Preferences 仅管理库：不提供 Space 勾选和 Alt+Enter 带回，不提交要求或请求模型，Esc 返回。已有采用项显示为只读快照；按 **s** 切换 Selected only，再 Enter 查看 **Selected snapshot** 与 **Current library entry**。修改／删除只针对当前库条目，已排队或运行中的请求及其原稿继续使用冻结正文。没有快照（包括恢复的旧记录）仍可管理库，不从库猜测过去采用了什么。库刷新只影响之后手动选择可用的条目，不回写冻结请求。

### 首次 refine 前选择

在 Preview 列表选中有完整背景的 `○ Unsent` **原稿父节点**，原稿下方直接展示内联 Preferences。**Shift+Tab** 从默认原稿列表直接聚焦偏好；Tab / Shift+Tab 循环原稿列表、原稿阅读、偏好选择。↑↓浏览，**Space 立即保存当前 Unsent 的勾选，不需要 Alt+Enter**；`/` 搜索，Enter / ↓ / Esc 结束输入。偏好区 Enter 只阅读全文，不启动请求；Esc 从全文返回偏好，再 Esc 回原稿列表，已保存勾选不会撤销。窄屏按焦点显示内容，短窗口优先展示当前操作区；偏好焦点暂停顶层左右切页与原稿动作。

Preview / Usage 都仍可按 **p** 或可用的 `preferencesKey`（默认 Alt+P）打开完整面板，管理库或深入检查；Usage 不增加内联选择。完整子页仍是 Space 暂存勾选、Enter 阅读、Alt+Enter 带回、Esc 放弃子页修改。从面板返回后刷新内联库，不撤销此前已保存的内联选择。勾选、阅读、带回和库管理均不请求模型，也不写 Pi 输入框。回到原稿焦点后，**Enter 才调用默认优化模型**；`m` → Enter 使用单次指定模型，同样携带已选要求，不发送给 Pi。

内联区显示 `Preferences · 数量 selected` 与用途分组的勾选列表，聚焦项显示短描述；其他摘要仍显示 `Preferences: 数量 · 名称`，未选时为 None。原稿树以 `P:数量` 标记已选项。选择按原稿身份隔离，内联勾选或子页带回后关闭并重新打开工作区仍保留于当前 session 内存；所有偏好均需用户手动选择，不根据草稿关键词自动勾选、不跨原稿继承，也不将 Unsent 或未提交选择写入 sidecar。当前 Unsent 编辑原样保留已有选择及指令快照，取消项不会因编辑而加回。已运行或旧轮次原稿通过 `i` 创建新副本时不继承偏好。

已选正文是快照，不在启动时重新读取库。首次运行携带独立的 `editing_instruction`，不拼入或修改 `draft`，也不改变 round 系统模板、历史或项目背景。开始排队即冻结要求；之后同原稿的重试／其他模型运行沿用同一份初始要求。已启动原稿不再允许修改其首次选择；希望换组合时用 `i` 创建独立原稿副本。详情参考区和 Usage 可阅读实际提交的 `Initial editing instruction`；sidecar 仅保留已提交的组合正文，不保存整份库、选择身份或背景，恢复后仍禁止原背景重跑。

内联每次勾选、子页带回时都检查原稿、选择、session、归档状态和运行状态是否仍匹配；发生变化或组合超过 `maxDraftChars` 时，内联拒绝本次操作并保留已有有效选择，子页保留暂存选择并显示警告，不套用到其他目标。已归档但背景仍完整的 Unsent 可重新打开选择器，运行继续使用旧背景；选择模板不刷新 round。模板 Add 表单不会预填原始任务。

Ctrl+\\ 捕获非空输入后仅打开 Unsent，不自动请求；想先选模板可按 Shift+Tab 内联勾选，或按 `p` 打开完整面板。空工作区可先管理库，再按 `n` 新建并保存原稿、选择偏好。

### 结果修订与共用模板库

Revise 中按 **Alt+P** 打开 Preferences，或用 **Tab / Shift+Tab** 在补充要求、Preferences、Review full requirements 间切换，Enter 打开焦点控件；任务详情的 `p` 仅管理库，不替代 Revise 选择入口。Revise 显示本次已选偏好名称与数量，无选择时显示 None，星号表示仅本次修改。Review full requirements 是只读的完整组合要求预览，可翻页滚动，Esc 回到补充要求；其中 Ctrl+S 不提交。管理操作只有始终可见的 **Add / Edit / Delete** 三项，不使用功能键。修订结果时，只有返回 Revise 后的 **Ctrl+S** 才请求模型；首次 refine 则返回 Unsent 后按 Enter。浏览、勾选、保存和带回均不写 Pi 主编辑器、不发送 Pi 消息。

- 默认焦点在列表：↑↓选择条目，Space 勾选／取消，Enter 阅读全文，Esc 从全文返回。宽屏左侧列表、右侧只读预览，窄屏通过 Enter 阅读正文。
- 在列表或操作栏直接按 **n 添加、e 修改、d 删除**，不用先 Tab 到按钮。搜索和表单中的这些字母仍是普通文字。
- **Tab / Shift+Tab 只切换 Search、Library、Actions 三个区域**。操作栏用 ←→（或 ↑↓）选择三项之一，Enter 打开；焦点用状态文字、前导箭头及选中背景标示。短／窄窗口优先显示当前焦点区域。
- 按 **/** 聚焦搜索，按名称或正文过滤，Enter / ↓ 回到列表；Ctrl+U 清空查询。搜索之外的勾选项仍保留，清空查询后可逐一取消。
- **Alt+Enter** 明确带回本次选择；根层 Esc 放弃暂存选择，不撤销已保存的库修改。回到 Revise 后恢复补充要求焦点，再 Ctrl+S 提交。允许只有偏好，偏好与补充要求全空则提示而不提交。候选过期或组合超长会保留输入与选择，不自动改绑来源。
- 从列表进入时，返回链路为：条目页 → 偏好列表 → Revise → 结果详情 → 请求列表。退出 Revise 保留当前结果的临时草稿；新结果不自动继承偏好。

焦点切换不读写库。筛选结果、正文排版按数据和宽度缓存；↑↓ / Tab / 翻页不会反复过滤整个库或重排同一长正文。首次显示内联区、重新打开完整 Preferences 以及从子页返回时加载／刷新库；子页内成功保存／删除后也会刷新。

已选项按勾选顺序组合，再追加自由输入，以两个换行分隔，正文原样保留。有元数据的正文使用 `Prompt rewriting instructions` 或 `Main-agent task requirements`，旧条目使用 `Saved editing requirements`；各段统一标注 `manually selected`。有已选项时，自由输入独立标为 `Current user instructions`，避免被误当作上一模板的正文。名称、描述、ID、版本和匹配条件不进入模型请求；当前纠正优先于冲突默认项，不把选择顺序当作覆盖明确约束的依据。

最多 50 项。同类型且正文完全相同的条目不能重复选入；提示后可在 Selected only 检查／移除已有快照。组合层也按选择顺序防御性去重；两个库仍独立可管理，不按名称覆盖或自动删库。移除后重新选择会捕获最新正文，取消后不会自动回选。自由文本不做可靠语义冲突检测。

**保存与管理：**`n Add` 预填完整自由输入，允许删减；Tab 按名称、正文、作用域、类型、描述、保存切换，Shift+Tab 反向切换。类型区分 Prompt rewriting / Task requirements；两类均仅手动选择，不再提供采用方式或 Auto 控件。新条目默认为手动任务要求；描述留空时使用名称。旧条目编辑保留原有语义，主动选择类型后才补元数据。正文 Enter 换行；底部提示跟随当前字段，按键加粗、说明弱化。子页 Ctrl+S 不保存也不提交。`e Edit` 修改高亮条目（作用域固定），`d Delete` 需要 y 确认。表单 Esc 遇到未保存修改时确认放弃；失败保留字段。保存成功不自动选中，以免重复应用自由输入中的正文。

已选项包含正文与元数据快照，库更新或删除不会静默改变它们。修改后先 Space 取消，再次勾选才捕获新版本；已删除但仍选中的条目继续显示，允许 Space 移除。Enter 全文可以检查库正文及已选快照，包含手动选择来源。临时输入及已选项仅在当前工作区内按候选隔离，关闭后清除；已提交组合正文沿用现有历史保存规则。

### JSON 元数据与手动选择

库支持旧版 v1；带元数据的写入使用 v2，防止旧插件静默丢失新字段。完整预制库见 [示例](../examples/prompt-refine-preferences.json)。条目中的 `metadata` 是 JSON 对象，不是需要再次解析的字符串：

```json
{
  "description": "手动选择后，必要时整理 prompt 本身的并列条目结构。",
  "kind": "rewrite",
  "activation": "manual"
}
```

- `kind: rewrite` 改变 prompt 的表达／组织；`kind: task` 补充主 Agent 的回答或行为要求，不替代原任务。输入时与原稿分开，输出时把适用且兼容的要求融入完整 prompt，保留原任务、适用的明确约束、条件和授权边界，合并重复并去掉 refiner 包装措辞。仅选择偏好不覆盖明确原约束或增加执行、工具、委派权限；当前用户明确要求的翻译、范围收窄等修改仍可生效。翻译 prompt 与要求英文回答属于不同类型。
- 所有偏好均仅手动选择。创建、捕获、编辑、复制原稿或直接 `/refine optimize` 都不会自动从库中选择条目。已删除中英文关键词、问句／列表／步骤检测和 `always` 自动采用链路；本地搜索仍保留，但搜索不勾选或提交偏好。
- 新写入的元数据只接受 `activation: manual`，不再接受 `match`。旧库中原本有效的 `activation: auto` 与 `match: always/parallel/sequence` 兼容读取为手动项，并移除内存中的匹配字段；名称、正文、ID、版本保持不变。加载不改写原文件，下一次对该库的显式保存／删除才落盘归一化元数据。非法元数据仍报错，不用空库覆盖原文件。
- 示例 Bullet / Step 与其他偏好一样仅手动。其正文仍保留条件边界：手动选择不证明一定要重排，清楚的原稿可以保持原样，不能把背景或引用变成任务、增加授权或改成主 Agent 回答格式要求。示例正文版本不自动覆盖用户库；已有快照仍需取消后重新选择才更新。
- 会话启动／reload 校验库；重新打开 Preferences、成功保存／删除后刷新可用条目。不在焦点变化、编辑原稿或模型启动时反复读取；已选正文和元数据仍是独立快照，排队后不再变化。
- Revise 不自动重放初始模板：只有本次明确提交的要求作为活动修订指令。初次手动编辑要求及紧邻上次修订要求可作为只读历史依据发送，用于解释候选中仍保留的编辑；禁止恢复已删除或已被纠正的要求，不累积完整修订链。预算紧张时先省略这份历史依据并告警。
- 插件只组织用户选中的正文，不额外调用模型选择模板，不把整份库、描述或配置字段注入请求。自由文本不做可靠语义冲突检测；当前明确任务及修订纠正优先于冲突的可复用要求，模板不能扩大执行或委派授权。

**库位置与配置：**

- 全局：Pi agent directory 下 `prompt-refine-preferences.json`。
- 项目：规范化 cwd 下 `.pi/prompt-refine-preferences.json`，不自动上探仓库、不跨 worktree 合并。
- 每个库最多 500 条、1 MiB；名称最多 120 字符，单条正文最多 16,000 字符；提交组合另受 `maxDraftChars` 限制。文件以 `0600` 创建，不随 session 历史清理。
- `preferencesKey` 默认 `"alt+p"`，在 Tasks / Usage（含 Inspect、空工作区）和 Revise 中可用；可改为不冲突的非功能修饰键，设为 `null` 可禁用快捷键。Tasks / Usage 的 `p`、Revise 内 Tab → Preferences → Enter 不依赖该快捷键。普通输入键、保留键、F1–F12 及其修饰组合均不可用；旧默认 `f2` 自动迁移到 Alt+P，其他功能键设置会告警并回退；加载本身不改写配置文件。与本扩展或 Pi 已解析绑定冲突时会提示，不能保证识别其他扩展／终端截获。
- 库写入通过同目录 `.lock` 文件协调多进程，并检查编辑版本。忙时重试；冲突时保留表单内容，取消并重新打开 Preferences 后再编辑。崩溃遗留锁只在确认没有写入进程后手工移除。损坏、未知版本或超限库不会被空库覆盖。外部编辑器若绕过锁写文件，不受这套并发协调保证。

实体终端的 Alt 组合键传递与中文 IME 仍需实际验收；自动测试覆盖组件、两种 Pi 渲染器、粘贴和异步状态，不能替代真实终端验证。

## 记录范围与用量

运行期日志最多 **100 条**，容量满时优先淘汰最早的已终结记录；未发送、排队和运行中工作不被静默淘汰。全部被待处理工作占满时拒绝新增并提示。日志按 session 隔离、跨该 session 的分支查看，不按项目聚合，不自动进入模型上下文。

### 用量与参考费用

详情保留精确 total、未缓存 input、output、cacheRead、cacheWrite、reasoning。按 Pi 规范化口径，总输入 = input + cacheRead + cacheWrite，命中率 = cacheRead / 总输入；缺少任一输入桶时不猜测总输入或命中率，总输入为零时命中率为 `—`。Reasoning 已含在 output 内，不重复相加。

费用采用本次响应的 SDK cost 快照，保留缓存和阶梯价格的 SDK 计算结果，不随以后模型价格变化重新计算。摘要用 `≈$0.012`；未知为 `Cost —`，明确可确认的零为 `$0`，非零小额为 `<$0.001`。SDK 返回零但模型目录没有有效非零价格时，保守视为未知，不能把零价占位宣称为免费。`(sub)` 来自宿主 OAuth 标识，表示订阅方式的参考价，**不是实际扣费或套餐额度消耗**。详情列费用拆分和解释；无跨请求费用汇总。取消后同 session 迟到的用量可以入账，但不会复活候选；手工编辑不继承模型调用费用。

### `/resume` / `/reload` 后的历史

默认 `historyPersistence: true`，在 session 文件旁保存 `<session-file>.prompt-refine.json`，不改写 Pi 对话或叶节点：

- 白名单保存原稿、结果、修订要求、模型/thinking、round/task/parent ID、状态、时间、用量与参考费用。**不保存完整对话背景、系统模板、项目规则／目录快照、请求 payload、会话标题、编辑器撤销快照或未提交输入。** 原稿／结果本身仍可能含敏感内容。
- 原子替换、文件权限 `0600`，每 session 最多 **100 条、2 MiB（UTF-8）**。优先保留完整的新记录；超容量或单条过大时省略整条并提示，不截断可接受的正文。此磁盘上限独立于运行期内存上限。
- 恢复记录全部归档，标注 `Restored history · background not saved`，保留原 Accepted / Sent 时间；这不代表编辑器现在仍有该结果。只恢复可查看记录，不恢复运行队列、当前候选、接受／发送动作或一次撤销状态。未完成调用标为 `Interrupted`。
- 可以查看、比较、显式接受、手工编辑或发送已有结果。**缺少背景时禁止原背景重跑／Revise**；选中条目按 `i Copy to current` 复制原稿，保存后再显式运行，使用当前 round 背景。
- `/tree` 不回滚这份 session 级日志；new/fork 不继承其他 session 的 sidecar；没有 session 文件路径时只使用内存。升级前没有保存的历史无法补回。
- 配置 `historyPersistence: false` 后 `/reload`，不读写 sidecar，不删除以前保存的数据。`/refine history clear` 确认后删除当前 session 的 sidecar，保留内存记录并暂停保存直到 reload，避免旧记录立即重建文件。
- 损坏、未知版本、session 身份不匹配或读写失败会告警并暂停写入，不覆盖原文件。手工删除或移动 Pi session 时，需要同步处理相邻 sidecar；不承诺宿主 `/resume` 删除操作会清理该文件。不要由多个 Pi 进程同时写同一个 session 的 sidecar。

Usage 中按 `b Storage` 可随时查询：保存关闭、没有 session 文件、尚无可保存记录、写入中、已保存，以及加载／保存／清理失败或清理后暂停等状态；同时显示实际 sidecar 路径、最近确认写入的运行编号、本次容量省略和仅内存／待写入的编号。同一运行已经落盘但最新结果或接受／发送状态尚未保存时，也列为待写入。此页只读，可滚动，Esc 返回，不发起模型请求或写入 Pi。

后台异步合并保存，正常 shutdown 会等待写入完成；强制杀进程可能丢失尚未写完的最后状态。

## 命令备用入口

```text
/refine
/refine 待优化文本
/refine optimize 待优化文本
/refine view
/refine usage
/refine history clear
/refine model
/refine cancel
/refine cycle
/refine restore
```

显式正文命令与 `r` 是明确发起请求，不受快捷键“只入列”规则限制，但不会取消其他请求。正文保留大小写与内部空白；与子命令同名时使用 `/refine optimize view`。Pi 可能在 slash command 提交时清空输入框；扩展只在空输入框中保留命令原稿，不覆盖其他草稿。

## 会话名称与兼容性

未命名会话可在同一次模型调用返回可选名称，预览单独展示，不混入 prompt。只有接受到编辑器或确认发送后才设置名称；Apply 不命名，不覆盖后来出现的手动名称。无效名称不影响有效 prompt；恢复草稿不撤销名称。曾经命名后，即使主动清空也不再次自动命名。

模型列表来自 Pi 已授权的 chat 模型；不借用或切换主模型，也不下载模型。默认 Shift+Tab 切换所选模型支持的 thinking；没有扩展覆盖时继承 session，缺失则使用 medium，再按模型能力调整。

仅支持 TUI 文本，不承诺保留附件、光标或选区。`Ctrl+\` 的终端兼容排查见 [快捷键排查](shortcut-troubleshooting.md)；不要在普通 Shell 提示符测试，它可能触发 SIGQUIT。自动化覆盖真实 Pi 渲染器，但仍需实体终端、IME 和真实 Provider 验收。
