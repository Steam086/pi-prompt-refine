# TUI 局部优化说明

## 当前结构

基于 `src/preview.ts`、`src/workspace.ts`、`src/panel-layout.ts` 的代码与渲染测试：当前 UI 是限宽单栏工作区，共用固定高度的头部、正文视口和操作区。主页面阅读候选结果，设置页管理上下文和优化器，输入页编辑新的优化请求。原稿、帮助和源码按需展开；状态区与编辑器中的实际草稿不是同一份内容。

## 参考原则与取舍

参考 `../pi-agents-tui/Pi-TUI-Guidelines.md`，采用以下适用原则：

- 工作区顶部增加主题分隔线，与 session 内容明确分开；主页面、设置页和输入页共用，极低窗口优先保留正文与操作。总高度与页面切换时的布局保持稳定。
- 用文字和主题样式共同识别当前页面，不只依赖背景色。页签不使用中括号，以留白分隔；活动页使用粗体和下划线，不再使用行焦点的箭头和背景，其他页弱化，窄屏优先保留当前页。导航已标识 Prompt Refine 时，状态行不重复品牌。
- 保持导航项位置稳定。设置中的长模型标识截为单行并用 `…` 标明省略，仅在选中项确实被截断时补充完整值，避免重复；模型选择器交互不变。
- 状态应诚实且可见。发送待 Pi 确认不等于已送达，固定头部保留 `Send pending · draft kept`，不因正文滚动消失。
- 滚动位置属于辅助信息。滚动时保留模型元数据；通知优先于滚动计数显示。
- 保持主题兼容和终端列宽约束，不引入固定 RGB 或字号。

不采用参考项目的双栏、圆角外框、项目身份色、近全屏尺寸及会话导航语义。保留本项目的单栏阅读宽度、固定视口、快捷键、保存时机、模型调用及发送逻辑。

## 快捷键与设置文字层级

- 空状态将 `No result yet.` 与下一行弱化的模型名组成正文中的居中信息块，不再紧贴导航；头部第二行留空，仅用于通知。窄小窗口退回有界换行与滚动，生成中和已有结果的布局不变。不显示无意义的 `Context: not captured` 或重复操作提示。`r` / `m` 集中在底部；没有任务或候选时不提示 Cancel，没有可发送候选时不提示 `Enter won't send`。帮助仍保留完整操作说明。
- 主页面、Settings、Input、Help 和模型选择器共用按键样式：按键为 `accent` + 粗体，说明为常规 `text`。快捷键按终端可见列（包括 ANSI、中文和宽字符）测量；需要时按列对齐，空间不足时省略完整提示，紧凑提示与单行回退保持相同样式。Settings 优先保留固定保存键和明确的取消范围。
- Settings 的 Enter / Space 只操作当前项；Context 复选项暂存，固定 `Ctrl+S` 在任意行保存 Context 并返回。底栏明确显示 `Save context`；有暂存修改时显示 `Discard context changes`，不会暗示撤销已生效的 Optimizer 设置。保存异常保留选择以便重试；配置写入失败但已在进程内生效时仍明确提示未持久化。
- 两个分组使用粗体标题，并在标题下分别标明 Context 手动保存、Optimizer 自动保存及主会话不变。模型选择和提示词编辑仍在各自确认后保存，thinking 切换立即保存。模型和编辑入口带有尾部箭头与 `Edit…`；thinking 不可用或等级固定时弱化显示原因，所有切换入口均禁用。
- Context 使用任务导向标签（项目规则、目录树、技能元数据），每项紧随弱化说明，不把配置说明伪装成资源已加载状态。仅分组边界保留空行；短窗口优先保留当前项及其说明，长模型等被截断值的详情紧跟当前项。保留稳定底栏和页面总高度；只有一行头部时，保存反馈优先于页签，不随正文滚动消失。
- 字段标签使用常规 `muted`，值与选项正文使用常规 `text`；不整行加粗，仅选中行通过 `accent` 箭头和统一正文宽度的背景区分。模型选择器的模型名也不再全部加粗。页面标题和活动页签保留 `accent` + 粗体，错误、未保存与发送状态保留语义色。

## 验证边界

自动化覆盖跨页面按键样式、Settings 保存/取消范围、任意焦点下的固定保存键、保存异常重试、thinking 禁用状态与快捷键保护、区域说明与完整行高亮、两行提示对齐、ANSI/宽字符列宽、Optimizer 和模型列表的明暗主题样式与字重调用、活动页样式、窄屏页名、长模型导航行、滚动元数据及待发送状态；原有测试覆盖明暗主题、Unicode 列宽、焦点、页面切换和真实 Pi 渲染器的终端输出捕获。尚未进行真人终端视觉、IME 或不同终端模拟器验收。极窄或极低窗口仍受可用行列限制，不承诺完整展示所有元数据与辅助说明。
