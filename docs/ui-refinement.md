# TUI 局部优化说明

## 当前结构

基于 `src/preview.ts`、`src/workspace.ts`、`src/panel-layout.ts` 的代码与渲染测试：当前 UI 是限宽单栏工作区，共用固定高度的头部、正文视口和操作区。主页面阅读候选结果，设置页管理上下文和优化器，输入页编辑新的优化请求。原稿、帮助和源码按需展开；状态区与编辑器中的实际草稿不是同一份内容。

## 参考原则与取舍

参考 `../pi-agents-tui/Pi-TUI-Guidelines.md`，采用以下适用原则：

- 用文字和主题样式共同识别当前页面，不只依赖背景色。活动页使用 `›` 和粗体，其他页弱化；窄屏优先保留当前页。
- 保持导航项位置稳定。设置中的长模型标识截为单行并用 `…` 标明省略，完整值仍作为选中项的辅助说明参与正文布局；模型选择器交互不变。
- 状态应诚实且可见。发送待 Pi 确认不等于已送达，固定头部保留 `Send pending · draft kept`，不因正文滚动消失。
- 滚动位置属于辅助信息。滚动时保留模型元数据；通知优先于滚动计数显示。
- 保持主题兼容和终端列宽约束，不引入固定 RGB 或字号。

不采用参考项目的双栏、圆角外框、项目身份色、近全屏尺寸及会话导航语义。保留本项目的单栏阅读宽度、固定视口、快捷键、保存时机、模型调用及发送逻辑。

## 快捷键与设置文字层级

- 主页面的两行快捷键共用列宽，按终端可见列（包括 ANSI、中文和宽字符）对齐。输入页和设置页的标准两行提示沿用同一布局；空间不足时整列省略，紧凑提示与单行回退仍保留。
- `Optimizer` 标题不再附带 `Applied immediately`。仅删除界面文案，模型、thinking 和优化提示词的原有生效时机不变。
- Optimizer 的字段标签使用 `muted`，值使用 `text`；选中项仅值加粗，箭头使用 `accent`，选中背景保持不变。小节标题继续使用 accent 和粗体，说明文字继续弱化，不整行加粗。

## 验证边界

自动化覆盖两行提示对齐、ANSI/宽字符列宽、Optimizer 明暗主题样式与字重调用、活动页标记、窄屏页名、长模型导航行、滚动元数据及待发送状态；原有测试覆盖明暗主题、Unicode 列宽、焦点、页面切换和真实 Pi 渲染器的终端输出捕获。尚未进行真人终端视觉、IME 或不同终端模拟器验收。极窄或极低窗口仍受可用行列限制，不承诺完整展示所有元数据与辅助说明。
