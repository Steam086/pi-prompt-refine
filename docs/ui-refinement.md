# TUI 局部优化说明

## 当前结构

基于 `src/preview.ts`、`src/workspace.ts`、`src/panel-layout.ts` 的代码与渲染测试：当前 UI 是限宽单栏工作区，共用固定高度的头部、正文视口和操作区。主页面阅读候选结果，设置页管理上下文和优化器，输入页编辑新的优化请求。原稿、帮助和源码按需展开；状态区与编辑器中的实际草稿不是同一份内容。

## 参考原则与取舍

参考 `../pi-agents-tui/Pi-TUI-Guidelines.md`，采用以下适用原则：

- 工作区顶部增加主题分隔线，与 session 内容明确分开；主页面、设置页和输入页共用，极低窗口优先保留正文与操作。总高度与页面切换时的布局保持稳定。
- 用文字和主题样式共同识别当前页面，不只依赖背景色。页签不使用中括号，以留白分隔；活动页使用 `›` 和粗体，其他页弱化，窄屏优先保留当前页。导航已标识 Prompt Refine 时，状态行不重复品牌。
- 保持导航项位置稳定。设置中的长模型标识截为单行并用 `…` 标明省略，仅在选中项确实被截断时补充完整值，避免重复；模型选择器交互不变。
- 状态应诚实且可见。发送待 Pi 确认不等于已送达，固定头部保留 `Send pending · draft kept`，不因正文滚动消失。
- 滚动位置属于辅助信息。滚动时保留模型元数据；通知优先于滚动计数显示。
- 保持主题兼容和终端列宽约束，不引入固定 RGB 或字号。

不采用参考项目的双栏、圆角外框、项目身份色、近全屏尺寸及会话导航语义。保留本项目的单栏阅读宽度、固定视口、快捷键、保存时机、模型调用及发送逻辑。

## 快捷键与设置文字层级

- 空状态将 `No result yet.` 与下一行弱化的模型名组成正文中的居中信息块，不再紧贴导航；头部第二行留空，仅用于通知。窄小窗口退回有界换行与滚动，生成中和已有结果的布局不变。不显示无意义的 `Context: not captured` 或重复操作提示。`r` / `m` 集中在底部；没有任务或候选时不提示 Cancel，没有可发送候选时不提示 `Enter won't send`。帮助仍保留完整操作说明。
- 主页面、Settings、Input、Help 和模型选择器共用按键样式：按键为 `accent` + 粗体，说明为常规 `text`。两行快捷键按终端可见列（包括 ANSI、中文和宽字符）对齐；空间不足时整列省略，紧凑提示与单行回退保持相同样式。
- Settings 的 `Context`、`Optimizer` 小节仅显示标题，不附带 `Enter Save` 等操作提示；默认头部不重复页面名。必要的保存/更改提示只放在底部，未保存和保存结果仍可见。上下文仍需 Enter 保存，返回仍丢弃未保存选择，不改变模型、thinking 和优化提示词的生效时机。
- Settings 的说明固定归属：Context 的三个选项各自紧随一段弱化说明，Optimizer 的作用范围说明固定在本区域末尾；不再随选中项增删说明或前置空行。仅两个区域之间保留一行空白，说明统一缩进并按可用宽度换行；Context 禁用警告也留在 Context 区域。长模型等被截断值的详情紧接 Optimizer 说明，不额外插入空行。
- 字段标签和小节标题使用常规 `muted`，值与选项正文使用常规 `text`；不整行加粗，选中项通过 `accent` 箭头和背景区分。模型选择器的模型名也不再全部加粗。页面标题和活动页签保留 `accent` + 粗体，错误、未保存与发送状态保留语义色。

## 验证边界

自动化覆盖跨页面按键样式、Settings 提示去重与全部选中项的区域/说明间距、两行提示对齐、ANSI/宽字符列宽、Optimizer 和模型列表的明暗主题样式与字重调用、活动页标记、窄屏页名、长模型导航行、滚动元数据及待发送状态；原有测试覆盖明暗主题、Unicode 列宽、焦点、页面切换和真实 Pi 渲染器的终端输出捕获。尚未进行真人终端视觉、IME 或不同终端模拟器验收。极窄或极低窗口仍受可用行列限制，不承诺完整展示所有元数据与辅助说明。
