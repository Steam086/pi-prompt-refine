# Architecture

Pi loads the root extension once per runtime. The native TUI, slash commands and session-events bridge use the same application. Clients attached to one hosted session see the same tasks and runs. The entry point registers handlers and the runtime wires together model access, storage and editor actions. [Extension entry point](../src/extension.ts) · [Runtime](../src/app/runtime.ts)

| When changing… | Ownership and contract |
| --- | --- |
| Rounds, queuing or cancellation | The [controller](../src/controller.ts) owns admission, duplicate matching and the receipt identities consumed by the application and TUI. The [journal](../src/history.ts) holds records and versions. The round ends when Pi starts processing a user message. |
| Model requests | The [original input factory](../src/app/request-flows.ts) captures the draft, projected history, project context and preferences for all entry points. The TUI decides when to submit a capture. [Completion](../src/app/completion.ts) budgets each request and calls the selected optimizer with an empty tool list. [Context and output protocol](context.md) |
| Configuration | The [configuration service](../src/app/config-service.ts) owns writes for the default optimizer, comparison thinking and Settings. Readers receive immutable snapshots. Accepted snapshots save in order. Capture and round creation freeze background, admission reads the current draft limit, and launch reads the request timeout and output budget. |
| Native TUI or editor actions | The [workspace](../src/workspace.ts) owns pages and focus. [Editor actions](../src/app/editor-actions.ts) handle accept, send and restore, including confirmation if the user has edited the draft. [UI conventions](ui-conventions.md) |
| Session changes and persisted history | [Lifecycle](../src/app/lifecycle.ts) closes stale views and switches the session’s [history store](../src/history-store.ts). Restored records contain reviewable text. Running a restored draft again requires copying it into a round with fresh context. |
| Slash, RPC or Web clients | [Commands](../src/app/commands.ts) route by host mode. The [application](../src/app/application.ts) shares the [operation contract](../src/app/operation-contract.ts) with its adapters and scopes reads, writes and retries to a runtime and session. The [wire decoder](../src/adapters/wire.ts) handles event calls. The [session-events bridge](../src/adapters/session-events.ts) owns framing and transfer limits. The [experimental Web client](../packages/pi-web/README.md) keeps its own form and reading state. |

Keep host capabilities with the module that owns the side effect. For example, closing a reader releases its subscription while a submitted run continues under the controller. [Application contract tests](../test/integration/application-contract.test.ts)
