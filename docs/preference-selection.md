# Preferences：检查选择与保存新条目

Preferences 有 Preview 内联选择与完整子页两种入口；浏览、选择和管理均不会请求模型、写 Pi 编辑器或发送消息。

## 项目默认与单次选择

在 `p` 完整面板的 Library 列表中，按 **g Project default** 为高亮项切换当前目录的默认状态；带 `*` 的条目已启用，预览／全文显示 **Project default: On / Off**。Project / Global 仍表示库保存位置，两种库的条目都可以设为当前项目默认。切换立即保存，只影响之后新建的原稿，不改变当前原稿的勾选或已冻结请求；根层 Esc 取消暂存选择也不撤销已保存的默认设置。管理操作栏仍只有 Add / Edit / Delete，Tab 顺序不变。

新原稿按启用顺序初始化默认项，获取独立的正文及元数据快照；同类型同正文防御性去重。当前请求可 Space 逐项取消，或在内联选择／完整面板的列表及操作区按 **c Clear all** 清空所有选择（包括被搜索隐藏的项），不清空自由输入，也不修改项目默认。内联立即更新当前原稿；完整面板仍须 Alt+Enter 带回，Esc 放弃本次暂存选择。搜索、全文和表单中的 g / c 不执行这些动作。下一份新原稿重新使用项目默认；修改已有原稿、同原稿重试／其他模型运行和 Revise 不重新套用默认。Enter／Ctrl+S 的显式提交边界不变。

默认身份按规范化 cwd 保存到 `.pi/prompt-refine-preference-defaults.json`，不自动上探仓库或影响其他目录／worktree；不增加 session 默认层。文件只有有序的 `project:id` / `global:id` 引用，最多 50 项／16 KiB，权限 `0600`，与两份库及 session 历史独立。会话启动／reload 和库刷新时读取默认及可用正文；其他进程修改后可重新打开 Preferences 或 reload 刷新。既有草稿不因刷新而变化。来源删除／不可用时告警并跳过，新原稿不使用过期正文；完整面板保留 Unavailable default 行，可用 g 关闭。损坏／未知版本／超限文件不覆盖，写入有原子替换和独立锁。

默认组合超过当前 `maxDraftChars` 时，仍可捕获为 Unsent 检查和取消；请求启动继续校验，直到减少选择或清空后才可提交。只有启用的默认正文进入请求，以 `project default` 标记；未启用条目及整个库不进入请求。

## Preview 内联选择（Unsent）

Preview 默认仅展示当前轮次。选中有完整背景的 `○ Unsent` 原稿父节点，右侧原稿下方直接展示有界偏好列表。默认焦点仍在原稿列表；**Tab 一次进入偏好选择**：宽屏临时以偏好列表替换左侧任务树，右侧依次展示原稿摘要、当前高亮偏好的描述与实际指令正文，以及有界的 Selected 名称反馈；浏览高亮只切换当前偏好预览，不改变已选内容。外层高度和分隔线位置不变。原稿阅读仍用 `o` 进入／退出。↑↓ / Page Up / Page Down 浏览，**Space 立即更新当前 Unsent 的选择，Enter 直接开始优化**，不用 Alt+Enter 带回或先切回原稿。**Esc / Tab 返回原稿列表，均不勾选、不提交、不撤销已经勾选的项**，Shift+Tab 同样返回；底栏优先突出 Esc 返回与 Enter 优化的按键。原稿焦点的 Enter 仍可直接开始优化。

- 偏好选择状态下 `o` 阅读当前条目的全文，Esc 返回偏好选择；全文中的 Enter、Tab / Shift+Tab 不会启动优化或离开阅读。Ctrl+S、Alt+Enter 和原稿动作不触发请求；只有选择状态的 Enter 明确提交。成功后选中对应模型运行（包括排队）；启动被拒绝则保留勾选和偏好焦点。顶层左右切页在偏好焦点内暂停，先 Esc 返回。
- `/` 进入搜索；Enter / ↓ / Esc 只结束文字输入，不提交，保留筛选，再 Esc 回原稿。搜索中的 Tab / Shift+Tab 不切到原稿，普通动作键是文字。查询、光标与阅读位置按原稿保留；筛选不改变已选项与组合顺序。
- 列表按用途分组，显示勾选状态；窄屏聚焦项附短描述，来源空间足够时显示 P / G。宽屏左栏随画布扩至最多 48 列，右侧原稿最多占六行，主要空间用于当前偏好的实际指令；描述最多三行，正文溢出显示 `o Read full`。名称标题使用中性加粗，描述使用常规 muted，原稿与指令正文使用常规 text，字面 Markdown 不额外加粗。没有描述的旧条目仍可预览正文。选中后不重排列表。来源变化／删除的快照带 `!`，`o` 可检查已选正文与当前库正文；不静默替换快照。库加载失败显示 warning，不伪装成空库，已有快照仍可查看与移除。
- 窄屏选择使用完整宽度，空间允许时保留一行原稿摘要；短窗口优先显示偏好列表。`o` 全文阅读使用整个内容区，Esc 返回偏好列表。右侧反馈不增加焦点，溢出时显示数量并保留最新勾选项可见；完整检查／管理仍走 `p`。不新增嵌套横向分栏。
- 每次 Space 校验当前原稿、session、运行状态与长度限制。失败不改变已有有效选择；已启动目标不再接受修改。选择只属于该原稿，关闭再打开仍保留于当前 session 内存，不作为库默认值或写入 Unsent sidecar。

`p` 或可用的 Alt+P 仍打开完整 Preferences 面板；子页独立暂存修改，**Alt+Enter 带回才更新原稿，根层 Esc 放弃暂存选择，但不回滚已保存的库修改**，不撤销此前的内联选择。库管理仍只有 Add / Edit / Delete。首次显示内联区时加载库，从完整面板返回后刷新；聚焦与滚动不重复读库。

Usage 的 Unsent 不增加内联区，仍通过完整面板选择。其他原稿／运行只浏览和管理库；结果追加要求通过 Revise → Preferences。

## 完整面板：All 与 Selected only

Unsent 按 `p` 打开完整子页；Revise 中按 Alt+P，或 Tab 到 Preferences 后 Enter。子页内只有 Alt+Enter **带回**后，返回 Unsent 按 Enter／返回 Revise 按 Ctrl+S，要求才进入请求。根层 Esc 放弃暂存选择，不撤销已保存的库修改。

Tab / Shift+Tab 仍然只切换 **Search、Library、Actions** 三个区域；管理操作仍只有 **Add / Edit / Delete**。子页显示选择数量、组合字符数和单项预览／全文，不提供当前与未带回组合的双全文预览；完整组合在带回后返回父级 Revise 的 **Review full requirements** 中检查。

- 在 Library 或 Actions 按 **s** 切换 All／Selected only；列表标题和按键提示显示当前视图及切换入口。短标签 `Selected` 指 Selected only。Search 和表单中的 `s` 是文字，不切视图。
- 每次进入 **Selected only 都从空查询开始**，因此能检查之前被 All 搜索隐藏的所有已选项。All 的搜索输入、光标和浏览位置独立保留；按 s 返回时恢复原查询与高亮身份，身份已移除时回到附近位置。
- Selected only 显示的是**已选快照**，按实际组合要求的顺序排列，不按库顺序或搜索排名排列。项可来自本次手动选择或显式配置的项目默认；名称、正文或元数据被库修改，以及来源已删除，都不会静默更新快照。警告以 `!` 标记；Enter 阅读完整状态、类型、身份和手动选择来源。
- Selected only 的预览／全文先展示 **Selected snapshot**；若与可用库来源不同，再单独展示 **Current library entry** 的实际当前名称、元数据和正文，方便比较，不重复冒充库正文。来源删除或库不可用时只保留快照并明确警告，不把缓存标成当前库。All 仍先展示库条目；Edit 和 Delete（含确认页）始终针对当前库来源，不修改快照。
- Selected only 内仍可用 `/` 搜索，但仅过滤快照，**不改变组合顺序**。新一轮进入该视图时会清空这份临时查询；All 的查询不受影响。Ctrl+U 可清空当前搜索。
- ↑↓ / Page Up / Page Down 浏览，Space 取消选中。取消后立即从 Selected only 消失；要重新选中，切回 All。All 中取消再勾选会捕获库最新版本并追加到组合末尾；已删除的快照一旦取消，不能从库恢复。
- Enter 阅读不改变选择；Alt+Enter 才带回全部选择（包括当前查询隐藏的项）。选择仍按原稿／候选隔离，库更新或删除不修改已选快照。取消的项不会因编辑原稿而重新出现；新建或复制原稿独立初始化项目默认，不继承来源原稿的选择。
- 同类型、同正文的跨库条目不能重复选入，失败显示 warning；可按 s 检查并移除已有快照后再选另一个来源。两个库来源仍可分别 Edit / Delete，不隐藏管理入口，不按同名覆盖。组合时也防御性去重；已选正文按用途与选择来源标记，自由输入独立标为 Current user instructions。

## 搜索规则

按空白字符分词，不区分大小写；**每个词都必须在名称、描述或正文的至少一个字段中出现**，允许不同词分布在不同字段。不做模糊匹配或去重音转换。

All 与内联列表先按用途分组：**Prompt rewriting → Task requirements → Unclassified**，优先展示 Refine 的核心改写能力，任务要求作为补充；这只是展示顺序，不改变已选项的勾选／组合顺序或冲突处理规则。每组内按以下搜索层级排序，同层保持候选原始顺序（库条目按加载顺序，已删除但仍选中的快照追加在后）：

1. 名称与去除首尾空白的完整查询相同；
2. 名称包含完整查询，或所有词都出现在名称中；
3. 所有词都能在名称／描述中找到；
4. 需要正文才能匹配的其余条目。

空查询或纯空白查询仍按用途分组，**仅组内**保持原始顺序，不是全库统一保序。Selected only 采用同样的匹配条件，但始终保留组合顺序，不按用途分组，也不使用排名。

## 新条目保存后定位

`n Add` 创建新条目，仍需在表单的 Save 字段按 Enter 明确保存。成功后使用库返回的 **scope + id** 定位，而不是名称或列表位置：

- 返回 **Library 焦点**，高亮刚保存的条目，便于 Enter 检查或 Space 显式选中；**不会自动选中**，也不会清空自由输入或改变已有快照。
- 新条目保存后返回 All 并清空搜索。若此前有查询或处于 Selected only，明确提示 **Filters reset to All**，避免新条目被过滤掉。此次新建定位取代之前的 All 浏览位置。
- 保存失败保留表单与字段，不重置视图、查询或选择，可重试或确认放弃。
- 保存已成功但重新加载失败时，明确报告 **Refresh failed after save**；保留已确认写入的条目供检查，并标记库不可用，不把旧缓存冒充新鲜库。若成功刷新表明新条目已被其他写入者移除，则提示无法定位，不把同名条目当成它。
- `e Edit` 保留原有编辑语义：作用域固定，保存后不自动选择、不退出当前视图或清空查询，也不替换已选快照。删除仍需 `y` 确认。
- 没有临时编辑快照或 Save as 入口。Add 预填的是当前自由输入，不是高亮库条目；跨作用域复用需手动复制正文，再用 Add 在目标作用域新建。取消选择不回滚已完成的保存或删除。

列表优先显示名称，只对聚焦行的名称使用中性加粗与选中背景。空间允许时附带弱化的 `P`（project）／`G`（global）和警告说明；长名称优先于这些辅助文字，警告标记保留在名称前。详细类型、ID 和手动选择来源放在预览／全文中。沿用同一有界面板和单个列表／预览分栏；完整子页用 Enter 阅读，Preview 内联用 `o` 阅读。

自动测试覆盖深浅主题、宽窄／短窗口、Unicode／ANSI、缩放、焦点、滚动、失败和带回流程，以及 regular／fullscreen Pi 渲染器。真实终端外观、Alt 按键传递和中文 IME 仍需人工验收；没有以终端输出捕获替代人工结论。
