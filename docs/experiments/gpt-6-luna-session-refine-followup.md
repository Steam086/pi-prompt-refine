# 原稿内 TUI 参考丢失：历史观察（脱敏摘要）

两次改写保留了末尾的讨论问题，却丢掉了问题所指的整段界面材料。另一次模型对照保留了材料。这个例子说明：**草稿中供主 Agent 阅读的引用不是可省略的会话背景**。反过来，简短确认所指的方案如果已在上文唯一确定，改写也可能有助于说明范围。

用空历史、空项目背景和当时的策略做过两次近似回放：有编辑要求的一次保留了界面，无要求的一次没有保留。样本不足以把差异归因于偏好或 thinking 等级；sidecar 没有保存原请求的冻结背景，不能用它复原完整调用。

这里不再刊载个人会话标识、偏好库标识、逐条操作时间、草稿或候选原文。后续协议对照、窄范围保护及其限制见[参考材料保留实验](luna-reference-preservation.md)；用仓库内脱敏的 fixture 检查格式，不需要打开真实会话。
